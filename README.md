# Mi Sitio con Next.js 15

Este un proyecto de practica donde se esta aprendiendo a usar Next.js, Tailwind CSS y TypeScript.

## Tecnologías utilizadas:
- **Framework:** Next.js 15 (App Router)
- **Estilos:** Tailwind CSS
- **Lenguaje:** TypeScript
- **Iconos:** Lucide React

## Estructura del proyecto:
- components/: Navbar, HeroSection, Blog y Footer.
- lib/: Datos centralizados para que el sitio sea fácil de editar.
- app/: Páginas y diseño principal.

## Cómo correr el proyecto:
1. Instalar dependencias: `npm install`
2. Correr modo desarrollo: `npm run dev`
3. Crear versión de producción: `npm run build`
